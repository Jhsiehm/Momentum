# Official-context diagnostic verification checklist v1

Independent reviewer executes this checklist **after** the root-authorized registered run. Do not refit, fetch sources, replace inputs or change frozen code. Report each check as passed, failed or not reached; a blocked or nonconverged run is not a successful experiment. This checklist itself records no executed verification.

## Integrity and boundaries

1. Hash the run registration and every registered input/code/protocol. Recheck acquisition registration bindings, full population ledger, source receipts, retained XML and feature files. Feature filenames must exactly equal the complete acquisition ledger's saved/ineligible feature dispositions, not an arbitrary surviving glob. Count missing/extra artifacts and preserve case IDs.
2. Replay the frozen source-only extractor for every saved feature, comparing all values, missing reasons, edition assertions, related IDs and raw source hashes. Independently inspect the feature-population registration boundary: every label-ledger case must be a previously sealed family representative. No labels used in acquisition, rankings, family choice or feature repair.
3. Rebuild connected components from selected source rows, external related identities and frozen known-family edges. Verify protected/exposed component exclusions, later-role priority even when the later row is feature-ineligible, one deterministic representative per surviving component, and disjoint training/117/118 families. Report graph limitations and all excluded IDs; automated agreement does not certify true family completeness.
4. Recompute the explicit outcome-proxy resolver for each sealed representative and compare every label, reason and maturity date. Check strict after-cutoff/before-Congress-end positives and law/action agreement. Negative proxies require supported history, post-Congress update and no contradictory enactment assertion. Unknowns remain unknown, with no replacement. This replay verifies rule execution, not a final-law census or true-negative certification.
5. Reconcile feature-population, label-ledger, label-exclusions and label-counts to accepted fitting/scoring IDs. Verify both training classes, each nonempty evaluation period and training maturity before earliest evaluation cutoff. List all unknown/date-ambiguous exclusions. If a gate fails, verify zero fit attempts and report the recorded blocker rather than demanding downstream artifacts.

## Numerical replay without fitting

6. Independently compute each observed training-context median; verify no field is entirely missing. Build raw twelve-column vectors from six anchors, imputed three context values and three indicators. Recompute training means/population standard deviations with .1 floor. Held-out values must not change any learned transformation. Compare every saved raw/scaled row, column order and training ID; anchor must be the first six columns of the same scaling.
7. For each saved fit, reconstruct its CSR matrix and coefficients. Compute logits, mean stable logistic loss plus .025 times squared slopes, and the gradient including .05 times slopes with unpenalized intercept. Require finite outputs and maximum absolute gradient ≤1e-6. Compare independently recomputed objective/gradient to both solver and runner verification. Confirm no more than two fit intents; preserve the exact count if failure stops after one. Do not call any optimizer.
8. Recompute every evaluation probability from the saved coefficients. Independently reconstruct Beta(1,1) rate and stage smoothing weight5 from matched training labels. Confirm reference and model IDs are identical and all probabilities were saved before scoring; probabilities themselves must not contain evaluation labels.
9. Independently recompute per-period Brier, clipped log loss, expected/observed events, class-specific Brier counts and ten fixed reliability bins. Verify equal-period mean losses and Brier skill as one minus the ratio of equal-period losses, not average percentage gains. Report context-minus-anchor and context-minus-stage differences, including adverse periods.
10. Replay the fixed10,000-draw global-family bootstrap, seed20261108, on sealed probabilities/outcome proxies without fitting. Verify valid/invalid draws, percentile endpoints and suppression below9,000valid draws. The adapter's internal text-name alias must map only to the context arm; public output uses context labels. Two exposed Congresses do not justify general political-environment significance claims.

## Required receipt contents

Record actual selected/requested/successful/feature-valid/label-valid/family-representative counts by Congress and role. Preserve every source failure and not-attempted ID, every feature/context missing reason, every family exclusion and every unknown label reason. Include all evaluation cases with ID, family, cutoff, source-proxy outcome/reason, four probabilities, and four per-case Brier losses. Record fitted coefficients/scaler hashes and all registration/result/review artifact hashes with reproduction commands. A case's raw XML remains ignored runtime; public summaries must not expose unrelated source content.

Distinguish independently replayed computational correctness from unverified historical availability, possible missing source history, proxy-label error, incomplete family graphs, collection/missingness bias and prior development exposure. Report tests, mock calls and actual optimizations separately. Do not claim timing, cost, human review, calibration, source completeness or predictive improvements that were not measured.
