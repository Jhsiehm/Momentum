# Bounded action-label source-contract diagnostic v1

The action-context predictive attempt halted with zero fits at the class gate. Its immutable ledger contains231 rejected cases with exact reason `Enactment action lacks public-law identity`. This diagnostic selects exactly those231 IDs from that existing ledger, verifies each remains unknown, and registers the sorted IDs and raw-source hashes before inspecting XML. No other case is inspected, no replacement or network call occurs, and no new outcome label is calculated. Existing rules, features, failed run and exclusions remain unchanged.

The motivating hr1071-113 record was already inspected by root: valid public-law identity assertions coexisted with source9/code36000 text `Signed by President.`. That prior exposure is explicit. The audit asks whether similarly coded but semantically distinct assertions explain the strict resolver's rejection, not whether these bills should become positives.

Using frozen hardened identity/scalar/container/date helpers, retain each own-law-list entry and every action with code36000 or E40000, including original text, stripped text, ordinal, source code and date. Classify exact frozen public-law identity text, exact `Signed by President.`, or other text. Mark source/code pair validity under the frozen policy and whether the public-law identity matches the record's list. Retain multiplicity and dates; compare each problem assertion date to the set of supported law-list-matching public-law assertion dates. Count distinct concordant dates and identities rather than silently resolving conflicts. Unsupported or ambiguous XML remains a case error. These are descriptive internal source agreements, not independent truth, historical availability or eligible positive labels.

Output `cases.json` contains every inspected case and literal terminal assertion; `errors.json` retains every failure; `result.json` gives exact case denominators and assertion-level cross-tabs by code/source/kind/date agreement. No horizon classification, replacement outcome resolver, label repair, prediction or fitting is included. A separately reviewed scientific decision would be needed for any later source-contract change.
