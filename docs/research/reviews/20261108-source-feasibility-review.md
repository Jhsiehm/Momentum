## Adversarial tests and pre-registration corrections

Eleven independent fixtures cover UTF-16 entity input, duplicate/missing object identities, invalid digests and numeric size strings, historical digest matches without public-access evidence, unrelated object digests, old dates attached to current bytes, archive traversal, archive member caps, missing package identity and malformed XML. The initial run passed ten and failed one: UTF-16 bypassed the original byte-string declaration check. The implementation was corrected before registration to reject null-containing/UTF-16 metadata. All eleven then passed.

Pre-registration code review also identified discarded partial response bodies, retry risk after interruption, a reset study clock on resume, weak package-name substring matching, empty object identifiers and ambiguous fixity children. These were corrected before the registered run. The final review confirmed persistent attempt markers and clock, retained partial responses, stricter package components/identity fields and per-route archive parse failures. No registered code or tests were edited during independent result verification.

The response timer is checked between reads with a fifteen-second socket timeout; it is not a hard thirty-second whole-response termination. The 900-second study budget is checked before initiating a route. Raw archives are inspected in memory rather than extracted to disk.
