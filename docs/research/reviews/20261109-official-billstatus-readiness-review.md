# Independent official BILLSTATUS readiness review

November 9, 2026. This review concerns a newly registered 100-case source-readiness sample drawn from 75,605 observed official-directory identifiers. It is explicitly separate from the blocked BICAM sample; it does not turn the BICAM audit into a pass or establish a predictive evaluation cohort.

## Preflight

Reviewed the collector, protocol and eight author tests before registration and requests. Added eight independent adversarial tests. **All 16 passed in normal and optimized Python.** Checks cover DTD/entity/NUL and oversized-body rejection, UTF-16 rejection, exact scalar identity/cardinality, mixed-schema ambiguity, requested-identity mismatch, exclusion of final-action and outcome text from derived values, absent versus empty context containers, response cap plus retained sentinel, and text-version URLs treated as metadata without fetching them. The author test independently specifies the first 100 ID hashes and verifies missing observed directory hrefs block sampling.

The fixed acquisition budget is 100 requests, no redirects/retries or replacements, each with a 2,000,000-byte cap plus one sentinel and a 20-second socket timeout. This is not a hard whole-run deadline. Every case and exact observed official URL is registered before acquisition. Complete raw XML may contain outcome information, and schema paths/version metadata reveal procedural progress; no claim of pristine or entirely outcome-blind evaluation is warranted.

Identity validity requires exact requested bill/Congress/type and a syntactically valid introduction date. Calendar consistency and the strict day-180-before-end flag are separate outputs. An identity-valid record can still have a date outside its Congress; these denominators must not be conflated. Context counts are schema availability observations, not verified timely features or evidence that a true zero is known. Full schema fingerprints retain unsupported structures for diagnosis rather than silently equating them with absent information.

## Postrun

Independent replay verified the registered 75,605-identifier population and exact first 100 hashes; all input/code bindings, request URLs, raw response lengths/hashes, XML identity/date fields, full schema-path counts/fingerprints, context counts and text-version metadata matched. All **100 requests returned HTTP 200**, all **100 parsed and passed identity checks**, and all **100 introduction dates fall within the calendar Congress**. Total retained response bytes: **1,441,575**. There were zero reported acquisition/parser/identity errors and no replacement cases.

**88/100** have a day-180 checkpoint before Congress end; the other 12 remain in this readiness sample. This is a calendar condition, not a certified at-risk cohort. All 100 have action histories with **469/469 syntactically valid action dates**, and all 100 have sponsor identifiers. **82/100** have cosponsor containers, covering **984/984 syntactically valid joining dates** and **3/3 withdrawal dates**. The other 18 missing containers are not established zero-cosponsor histories. These date checks do not certify completeness, semantic accuracy or contemporary public availability.

All 100 have text-version metadata, totaling **122 records with URLs**. **98/100** have exactly one matching introduced-edition metadata record with a URL; **87/100** satisfy both that metadata condition and the calendar day-180 condition. Two cases lack an introduced-edition record: `hr2787-113` exposes only a Reported in House version, and `s4805-116` only a Placed on Calendar Senate version. They are retained, not replaced. No linked bill-text document was downloaded or validated by this run.

The root `version` attribute is absent in all 100 documents, so that particular scalar is null; full schema fingerprints remain present. The absence of that attribute does not imply unparsed XML or absence of every schema-version indicator. Later edition names and schema structure reveal procedural progress; no pristine outcome-blinding claim is made. No label extraction or scoring was performed.

The primary independent receipt is `data/research-runs/official-billstatus-readiness-v1-20261109/independent-review.json`, SHA-256 `92708cef4964c671c55aa160227e51c98c7e69bf07ee660c8ea25c4eba73d421`. It includes all 100 per-case source/inspection hashes and calendar/version results; a standalone `independent_verify.py` reproduces the checks without importing the production inspector. The supplemental `independent-coverage-review.json`, SHA-256 `35125a074c13517599775e652249140728629730c500353655bf8c4f97a3b462`, verifies all aggregate context counts and 98 introduced-plus-two-missing case records. The supplemental verifier initially assumed the 98-entry list included the two separately listed missing cases; that verifier assumption was corrected before the successful receipt. Source artifacts were not changed.

Independent review issued no network requests and fitted no models. The audit establishes that these official current records are a practical metadata route for further bounded source/feature work; it does not validate a predictor, negative labels, family independence, complete withdrawal histories, historical source timing or the 60% target.

## Conditional methods decision review

Reviewed the separate proposed two-fit context diagnostic. Its separation from E3, fixed earlier training/later evaluation, unchanged target and stage/rate references, complete-case matching, and explicit pre-score three-field revision are coherent. This is conditional design approval, not execution release. Exact publication-edition semantics, action/referral mappings, cosponsor-history completeness, date precision, families and negative-label resolution remain required. The existing structured scaler accepts six columns, so the proposed nine-column arm needs a separately versioned dimension adapter and numerical preflight; the frozen solver must not be silently rewritten. No model outcomes informed this review.
