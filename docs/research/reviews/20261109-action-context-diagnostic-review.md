# Independent action-context successor review

## Preflight

This is a separately registered, adaptive retrospective study following the publication-anchor failure. It does not revise any predecessor artifact or certify historical source availability. The source sample and law-list conditioning association have already been exposed.

Independent review checked the new feature extractor/preparation wrapper and two/eight-column fit runner. **39 synthetic tests passed normally and under optimized Python:** 9 author plus 8 independent feature tests, and 12 author plus 10 independent runner tests. Optimizer calls in orchestration tests are mocked; these are not real model fits or predictive evidence.

Feature checks cover both official identity schemas, absence or empty dates in publication metadata having no effect, exact source9/origin-chamber milestone meaning, strict cutoff equality, future/enactment codes not advancing the milestone, duplicate dates, absent pre-cutoff activity, and explicit exclusion for unsupported later action sources. Three context helpers and the outcome resolver are imported unchanged from frozen predecessors. Other action codes remain opaque for baseline purposes. The preparation binds all 12,000 original source/receipt/feature artifacts, original dependencies, the new proposal and retained primary guide. Every identity is processed uniformly; no download, replacement, label resolution or optimization occurs in preparation.

Whole-history date/source validation can still exclude a case because of later record quality. Consequently this is not a purely pre-cutoff eligibility policy; exclusion associations must be reported. Milestone0 means no recognized assertion in observed supported history, not proof that no progress occurred.

Runner checks cover training-only median/scaling, exactly two/eight columns, all-missing stops, external protected-family bridges, later-period priority even for ineligible later rows, unchanged family selection salt, maturity/class gates, missing artifacts failing before labels, and independently recomputed gradient rejection of a falsely accepted mocked solver result. A review finding led to an explicit predecessor-population comparison artifact, including added/removed IDs and changed family representatives, saved before labels. It has no influence on selection. The runner directly calls the unchanged v2 proxy resolver and saves probabilities before scoring.

**Source-only preparation is released after preflight.** Fit release remains conditional on full source replay, available training context values, immutable registration and all existing class/maturity/numerical gates. Neither this release nor the software checks establish predictive improvement, reliable negatives, adequate event counts, historical eligibility or achievement of the60% target.
