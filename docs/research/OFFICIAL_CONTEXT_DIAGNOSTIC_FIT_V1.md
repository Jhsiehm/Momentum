# Official current-record context diagnostic: fit protocol v1

This protocol governs a new explicitly retrospective source-proxy experiment, not E3 or a historically validated forecast. Its source-selection/feature/outcome definitions are in `OFFICIAL_CONTEXT_DIAGNOSTIC_V1.md` and the independently reviewed methods decision. Two logistic artifacts maximum; no calibration, tuning, retry or promotion. No implementation here modifies registered solver or previous experiments.

Verify acquisition input bindings, every saved feature/source/receipt and replay the source-only extractor. Pin those inputs, this runner, feature code, unchanged sparse solver, prior metric/bootstrap code, tests and protocols in a fresh registration. Source files may contain outcomes, but only the separate resolver reads them into derived values after the feature-population seal.

Build a union-find family graph from all saved source-feature rows and every related identity, including external nodes; add existing frozen family edges and protected/exposed exclusions. A component touching any banned identity/family is excluded. Before labels, later periods have priority: 118 over 117 over training (113–116), including when the later source has ineligible features. Within the highest role choose one eligible family representative by SHA-256 of the experiment version, newline and identity. No label-dependent replacement. Save graph, features, representatives and every exclusion before outcome resolution.

Resolve outcomes only after the source-feature population seal. Save all positive/negative-proxy/unknown labels and counts before applying label eligibility. Training requires both classes, evaluations 117 and 118 each nonempty. Training label maturity (enactment date for positives; Congress end for negative proxies) must precede the earliest retained evaluation cutoff. These are computational requirements, not evidence of adequate event counts, historical label availability, certified negatives or independent validation.

Fit three context medians only on the retained training rows. A field entirely missing in training blocks the whole experiment. Concatenate six valid anchor features, three transformed context values with training-median replacement, and three explicit missingness flags: twelve columns. Fit training means and population standard deviations, floored at .1, once; use the first six columns for the anchor and all twelve for the context arm. A separate adapter supports twelve columns; the frozen six-column API and sparse optimizer are unchanged. Save exact IDs, raw and standardized matrices, labels, medians/scales and references before optimization.

Run exactly one zero-initialized fixed sparse optimization per arm using the existing L2=.05 objective and independently recomputed gradient tolerance1e-6, maximum20,000iterations. Anchor first, context second; failed convergence stops without retry. Record fit intent before each call, including fit-input hash. Six-hour fit-stage wall cap; fail and preserve partial outputs. Fit cap is two; the two later Congresses share the same fixed artifacts.

Historical-rate reference is Beta(1,1) on matched training rows; stage reference is `(stage positives+5*rate)/(stage rows+5)`, stage0–3, empty stages fall back to rate. Save all probabilities before scoring. Report each evaluation period and equal-period mean Brier/log loss, event counts, expected events, class losses, fixed ten-bin reliability and Brier skill against both references. Reuse the previous family bootstrap with10,000draws and seed20261108 through an explicit context-name adapter; no change to arithmetic or tuning. The interval remains descriptive on exposed, source-conditioned populations with provisional families and only two political periods. Zero-event evaluation suppresses class-specific estimates naturally; it does not authorize enrichment.

The failure record preserves fit attempts even when the run cannot complete. Runtime remains ignored. Independent review must verify source/code bindings, population and label gates, training-only transformations, numerical objective/gradient, probabilities and metrics without extra fits. No successful diagnostic is automatically promoted or described as reaching the60%forecast target.

Reproduction (only after independent preflight/root execution authorization): `python3 -m scripts.official_context_diagnostic_v1 --source ACQUISITION_DIRECTORY --output FRESH_IGNORED_DIRECTORY`.
