# H.R. 5925 introduction-date reconciliation

The blocked v1 check conflates publication issue date with legislative introduction date. The frozen sources agree on introduction: **October 11, 2023**. The introduced publication was issued with the subsequent referral date, **October 25, 2023**.

| Official field | Value |
| --- | --- |
| BILLSTATUS `bill/introducedDate` | 2023-10-11 |
| MODS `extension/action` saying “introduced the following bill” | 2023-10-11 |
| MODS `extension/action` referral | 2023-10-25 |
| MODS `originInfo/dateIssued` | 2023-10-25 |
| Introduced bill XML `form/action/action-date` for introduction | 20231011 |
| Introduced bill XML referral action date | 20231025 |

The [official introduced text](https://www.govinfo.gov/content/pkg/BILLS-118hr5925ih/xml/BILLS-118hr5925ih.xml) corroborates the distinction already present in the frozen [MODS metadata](https://www.govinfo.gov/metadata/pkg/BILLS-118hr5925ih/mods.xml). The introduced text was fetched during this investigation; its retrieval is not proof of historical availability. Source bytes, original retrieval receipts and SHA-256 hashes are retained under `data/investigations/hr5925/sources`, with structured findings in `report.json`.

The v1 validator in `engine/cohort.py` requires `issued_at[:10] == introducedDate[:10]`. That rule rejects a valid distinction in this case. It is left unchanged, as are the v1 protocol and result.

A separate version can apply `engine/publication_identity.py::validate_introduction` uniformly to every sampled introduced package. It requires exact package identity and an explicit introduction action agreeing with BILLSTATUS, rejects missing or conflicting action dates, rejects issue dates earlier than introduction, and preserves the distinct issue date. The original conservative MODS/PREMIS availability check must still apply. No bill-specific exception or checkpoint shift is justified.

This is machine-assisted reconciliation, not human signoff. It does not resolve training-label timing, establish historically identical source bytes, permit scoring by itself, or unlock the action-history experiment.

```sh
python3 -m unittest tests.test_publication_identity
```
