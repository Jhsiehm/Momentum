# Collection Explore evidence contract

Explore uses the latest saved collection membership by default, or an explicit saved `collection_version`, and its dataset, with a selected evidence cutoff. Every bill title, topic, chamber, stage and event comes from records both effective and demonstrably available by that cutoff. Missing metadata stays visibly unavailable. Current watch settings and saved membership are user workspace state, not historical legislative evidence.

The comparison window defaults to 90 days and accepts 1–730 whole days. `new_event_count` means newly eligible evidence source keys since the previous cutoff, **not** necessarily actions that occurred during the window. `effective_event_count` counts only those newly eligible events also effective during the window. Refreshing the same source key does not count as a new event. `stage_change` is a difference between eligible snapshots; it is null when the earlier metadata was unavailable. `newly_available` denotes first eligible metadata. Changes may reflect late arrivals or source corrections, not contemporaneous legislative movement.

Bounds describe retained record coverage; they are not promises of complete history. Future cutoffs clamp to the current instant. Demo collections default to 2023-07-01. Replay collection coverage reports metadata eligible at the selected cutoff, not present-day imports or experiment eligibility. No forecasts are fitted or probabilities invented by Explore; stage is a recorded event classification, not a likelihood of enactment. The map and flat views must use the same rows as the table and explain their axes.

Explore is available from each saved collection, with linked Map, Flat and Table views, a bill inspector, filters, replay controls and a changed-evidence list. Dates display in UTC; Latest evidence explicitly requests the current instant.

Map renders one labeled prism per visible evidence row on a continuous warm-paper SVG isometric survey plane. Topic strips organize the shared surface; placement within a strip is a layout choice, not a measured axis. Prism height represents the latest evidenced legislative stage, never forecast probability. Clay identifies the selected bill; unavailable evidence has a pale dashed treatment. Map, Flat and Table share the filtered rows and selected bill.

Drag to pan, use the zoom buttons, or choose Fit map. Selecting a bill preserves the current pan and zoom. Keyboard users can focus bill marks, select with Enter or Space, and navigate with arrow keys or Home/End. Replay controls follow the landscape; the adjacent inspector stacks below it on narrow screens, where camera controls remain available.

Ask about this view opens a chat with a visible context bar. The server validates and persists the collection version, selected bill, cutoff, comparison window and filters, recomputing visible membership from eligible evidence. Evidence-tool calls inherit omitted view settings; explicit tool arguments can request another scope. Filtered summaries and navigation artifacts retain this scope, while collection membership and experiment proposals remain whole-collection operations. Clear context removes the scope for subsequent messages.
