# Lessons and prevention checks

Read before related scheduled work. These are verified engineering/research lessons, not automatic model training.

- Repeating a frozen cohort does not increase independent evidence. Compare input hashes and label reruns reproduction.
- A lower score on an all-negative evaluation cannot establish finding enacted bills. Report outcome class counts and require suitable temporal evaluation before promotion.
- Current economic revisions leak into retrospective prediction. Require matching ALFRED vintage headers and strictly prior availability; reject missing/stale observations rather than quietly imputing.
- Generic experiment rerun handlers can silently substitute a different model. Dispatch by study kind and verify the saved reproduction hash.
- SQLite INSERT OR REPLACE can evade update/delete-only immutability guards. Test replacement attempts as well as updates/deletes.
- Historical bill navigation must carry the report cutoff. Test that links preserve dates and return context.
- Async UI errors may arrive after navigation. Check the active generation before updating page elements.
- Agent evidence review is not a human audit. Preserve review provenance and leave human approval fields untouched.
- A later-preserved source can block an earlier training split even when outcomes themselves are old. In the November 5 cycle, a separately audited 114th final calendar plus sampled dated-law proof established earlier bounded availability. Use a new protocol, exact complete-census crosscheck and date proof; never backdate current imports or alter frozen studies.
- More resolved examples and changed weights do not guarantee lower loss. The full-cycle fixture test increased training from 240 to 300 but slightly worsened Brier; preserve primary/secondary metrics and reject unsupported promotion.
- Retaining selected weights alone does not satisfy a promise to retain every trial. Save candidate coefficients/scaling alongside predictions and training hashes; verify reconstructed trial probabilities exactly.
