## Exact question and execution

Could an archive index supply a successful pre-cutoff capture of each official introduced XML rendition? The first plan used the exact eight current GovInfo addresses from the sealed prior audit. After those results, a separate follow-up used eight inferred FDsys predecessor addresses, based on official migration examples. The alias phase was adaptive and separately sealed before its own requests; it was not planned before the first results. The inference does not prove each legacy address actually existed.

Each plan allowed eight requests, zero retries/redirects, an eight-second socket timeout, one-million-byte response bound, no new requests after 120 seconds, and stopping on first HTTP/transport/parse error. These are exploratory metadata checks with exact-URL match, capture time no later than the original cutoff, HTTP-200 filter and one-result limit. Neither the request timer nor socket timeout is a strict whole-run deadline. Scripts rely on the frozen eight-row input rather than an explicit loop-count cap; actual requests complied. Do not generalize or rerun them as a reusable collector.

The methods review confirms that preprocessing and numerical checks now have evidence, but the exact matched population, historical-source eligibility, designated reviews, positive-family scope, class coverage and execution registration remain unresolved. Existing raw training positive counts are 116/158/227 and evaluation positive counts 75/48/59. If the 200/100 floors apply per fold, two training folds and all three evaluation folds fail even before source exclusions. These are previously recorded unreviewed appearances, not newly counted accepted families; overlapping folds cannot be summed to pass a gate.

The prospective assessment identifies a source-only immutable capture ledger and verifier as a separate implementation gap. The current live recorder uses a different model and arbitrary age and cannot satisfy the research paper's day-180 paired issuance contract. No collector was implemented or activated by this assessment. Collecting text now cannot retroactively certify historical training; if new cohorts must supply training labels, those cohorts must mature before fitting, followed by later untouched evaluation. The existing structured paper's future timetable and model artifacts cannot simply become a text study.
